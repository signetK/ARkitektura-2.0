# 📱 ARkitektura  
*A Mobile Augmented Reality Application for QR Code-Based 3D Visualization and Description of Mariano Marcos State University (MMSU) Buildings*

---

## 📖 Project Description  

### 🔹 Background  
Navigating and understanding the layout of university buildings can be challenging for students, faculty, visitors, and tourists at MMSU. Traditional maps and static signage often fail to provide an engaging or comprehensive spatial understanding of the campus structures.  

---

### 🔹 Problem  
- Students and visitors often struggle with identifying buildings and understanding their purposes.  
- Static maps provide limited interactivity and engagement.  

---

### 🔹 Solution  
**ARkitektura** leverages **Augmented Reality (AR)** and **QR Code technology** to provide interactive 3D building visualizations along with informative descriptions.  

By scanning a QR code, users can:  
- View MMSU buildings as **3D models** overlaid in real-world environments  
- Access **historical and contextual information** about each building  

---

### 🔹 Key Technologies  
- **ARCore / SceneView** → AR visualization  
- **QR Code Scanning** → Model triggering  
- **3D Models** → Created using Unity3D or Blender  
- **Android Development** → Kotlin + Java integration  

---

## 🛠️ Key Tasks  
- Designing a **user-friendly UI/UX** tailored for MMSU stakeholders.  
- Developing the **QR code system** linked to building data and 3D models.  
- Creating or sourcing **accurate 3D models** of MMSU buildings.  
- Implementing **smooth AR rendering** of models in real environments.  
- Integrating **descriptions and historical facts** into the app.  
- Conducting **usability testing** and refining the system based on user feedback.  

---

## 👥 Intended Users  
- MMSU faculty and staff  
- Current MMSU students  
- Incoming freshmen and transferees  
- Students from other campuses  
- Local and international tourists  
- Visitors attending events or partnerships  
- Local community members  

---

## 🎯 Objectives  

### General Objective  
To design and develop a functional prototype of a mobile augmented reality application for visualizing and learning about MMSU buildings using QR code-triggered 3D models and descriptions.  

### Specific Objectives  
1. Design a **user-friendly and visually appealing UI/UX** for the AR mobile application.  
2. Develop a prototype that integrates **QR code scanning** to trigger 3D building visualizations.  
3. Implement **smooth and interactive 3D rendering** in AR.  
4. Integrate **easy-to-understand descriptive content** for each building.  
5. Conduct **usability testing** and refine the prototype based on feedback.
